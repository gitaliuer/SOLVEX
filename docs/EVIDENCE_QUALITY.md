# Research: происхождение, даты и расхождения

Дополнение 30.09.2026 по прямому запросу Али. Главный экран сохраняет фиолетовый hero; ниже — интерактивный пример Agent без вымышленных достижений.

Research по-прежнему отделён от данных бизнеса и подтверждённых полей. Новый отчёт содержит `quality_version: 1`, сведения `metadata` у каждого источника и `comparisons` (до трёх пар фрагментов). Старые отчёты читаются без миграции, с пометкой, что проверка ещё не выполнена.

Метаданные научных работ сверяются по точному DOI из URL с публичным Crossref API. DOI извлекается из doi.org/dx.doi.org и известных DOI-путей Wiley, SAGE, Taylor & Francis, ACS, Science, Springer; произвольные домены и параметры не используются. Запросы идут только на фиксированный HTTPS-хост api.crossref.org, без переходов на пользовательские URL и редиректов. Проверяются первые шесть источников, не более двух запросов одновременно, 6 секунд на lookup, тело до 512 КиБ. Только совпадающий DOI позволяет записать дату публикации, тип документа, издателя и журнал. Год без месяца не превращается в вымышленную полную дату. Ошибка, отсутствие DOI или метаданных оставляют дату неизвестной. Crossref содержит сведения издателей: наличие DOI или журнального типа не доказывает рецензирование, достоверность или отсутствие отзыва статьи. Возраст источника не равен низкому качеству.

AI сравнивает только реально полученные цитированные фрагменты. Каждая пара содержит `left_id`, `right_id`, `relationship` (`conflict|different_context`), `summary`, `caveat`, `next_check`. Сервер требует разные фрагменты с непересекающимися источниками. Это возможное расхождение по найденным материалам, не экспертный систематический обзор. Пустой список означает «явных расхождений не выделено», а не научный консенсус. Даты и URL не генерируются этим AI-шагом.

Модель и параметры поиска одинаковы для всех тарифов. Документация: [OpenAI web search](https://developers.openai.com/api/docs/guides/tools-web-search), [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/tips-for-using-the-crossref-rest-api/).
