# AI Agent: диалог и состояние задачи

По прямому поручению Али интегратор меняет сервер, AI и web. Старый мастер заменяется постоянным диалогом, карточкой рядом и подтверждаемой готовностью.

- `POST /api/me/agent` `{request_id: UUID}` создаёт пустую личную задачу идемпотентно; повтор возвращает ту же. Тема по умолчанию «Без темы».
- `GET /api/me/agent/{task_id}` возвращает `{task, messages, run}`. Доступ только владельцу BUSINESS, записи переживают перезапуск. Старые личные задачи также открываются в агенте с пустой историей.
- `POST /api/me/agent/{task_id}/messages` `{request_id: UUID, text: string(1..6000), revision: integer}` сохраняет сообщение до обращения к модели. Повтор успешного запроса не вызывает модель; повтор неудачного запуска не дублирует сообщение. Одновременно допускается один запрос на задачу. `run` содержит status pending/completed/failed, безопасную ошибку и ID запроса; ожидание более 90 секунд считается прерванным, можно повторить. История ограничена 100 пользовательскими сообщениями на задачу.
- Первый ответ содержит минимум три уточняющих вопроса. Далее агент отвечает на свободные сообщения, учитывает историю и текущую карточку, спрашивает только существенное неизвестное. Структурированные изменения карточки собираются из дословных источников пользователя; ответы AI не являются источником фактов. Пустые сведения не заполняются догадками. Агент не подтверждает факты, не публикует и не выбирает команды.
- `Task` дополнен `revision`. `PUT /api/me/tasks/{id}` принимает необязательный `expected_revision`; конфликт даёт 409. Каждое изменение и публикация повышают revision. Ответ AI применяется только к той версии, на которой начался запрос. Ручное изменение в другом окне не затирается; запрос отмечается failed с предложением повторить. Для опубликованных задач чат работает в режиме обсуждения, изменения карточки только вручную.
- Изменённые агентом поля теряют подтверждение. Рейтинг 0–100 по прежней формуле, растёт после ручного подтверждения и сохранения; заполненность отдельно. Публикация доступна с любым рейтингом и непустым названием.
- Все записи только в серверной SQLite. Клиент хранит только ID текущей задачи/запроса, без истории и секретов. CSRF, сессии и изоляция аккаунтов обязательны. Неудача AI явно отображается, шаблонного ответа вместо AI нет.

API использует существующий серверный клиент и настройку модели. Схема ответа проверяется по рекомендациям [OpenAI Docs: Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), источники дополнительно проверяются приложением.
