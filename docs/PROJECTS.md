# Проекты и дорожная карта — 30.09.2026

По поручению Али интегратор реализует следующий этап в сервере и web. Один проект на выбранный отклик; бизнес явно нажимает «Начать проект». Несколько выбранных команд — отдельные проекты. Невыбранный/чужой отклик не подходит. Создание повторяемо без дублей. Сохраняется снимок карточки и предложения на момент старта; последующие правки задачи не подменяют договорённости. Просмотр — только владельцу задачи и аккаунту выбранной команды. Email не раскрывается.

GET /api/me/projects — свои проекты; POST /api/me/proposals/{id}/project — BUSINESS+CSRF; GET /api/me/projects/{id} — участникам. Проект содержит revision, status active|completed, snapshot, профили сторон, milestones и events. PATCH проекта {expected_revision,status} — бизнес; завершение разрешено только при наличии этапов и приёмке каждого, возврат в active разрешён вручную.

POST /api/me/projects/{id}/milestones {expected_revision,title,description,due_date:null|YYYY-MM-DD} — бизнес. До 30 этапов. PUT /api/me/projects/{id}/milestones/{mid} с тем же содержимым — бизнес, только planned. Сроки и результат вводят люди; автоматически выдуманных этапов нет.

POST /api/me/projects/{id}/milestones/{mid}/action {expected_revision,action:start|submit|approve|revise,note,result_url} — CSRF. Команда переводит planned/changes_requested в in_progress, отправляет результат из planned/in_progress/changes_requested в review (note 10–3000, необязательная HTTP(S) ссылка до 500). Бизнес принимает review→done или возвращает review→changes_requested с замечанием 3–3000. Принятый этап неизменяем. Последняя сдача хранится на этапе; история всех сдач и замечаний остаётся в events. Завершённый проект не меняется до явного открытия бизнесом.

Каждая мутация проверяет общую revision в BEGIN IMMEDIATE, при устаревшей форме 409, ввод остаётся у пользователя. Максимум 1000 событий. При первой приёмке любого этапа проекта — +10 команде один раз на отклик (прежнее правило); ранее начисленные баллы не повторяются. Старый endpoint подтверждения этапа для проекта блокируется; отклик с проектом нельзя отклонить задним числом. Старые решения/баллы не мигрируют автоматически в проекты.

UI: раздел «Проекты» обеим ролям, переходы из откликов, карточки проектов, прогресс по принятым этапам, дорожная карта, ожидаемый результат и срок, сдача результата/замечания/приёмка, журнал работы, завершение и открытие проекта. RU/EN и мобильная версия. Research/Evidence не запускается в этом этапе.
