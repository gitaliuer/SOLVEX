# Фото задач и переписка, 30.09.2026

По прямому поручению Али интегратор добавляет фото, способы связи и спокойные поверхности кабинета, сохраняя фиолетовый первый экран и акценты AI. Существующий контракт откликов и ручного выбора остаётся в силе.

## Фото

До пяти фото на задачу. Только владелец BUSINESS загружает, удаляет и выбирает обложку. PNG/JPEG/WebP до 3 МБ и 16 Мп декодируются, поворачиваются по EXIF и сохраняются без метаданных в WebP до 1600 px. Черновые фото доступны только владельцу; опубликованные — посетителям каталога. Ответы изображений no-store. Фото не становятся фактами AI и не влияют на рейтинг.

- `POST /api/me/tasks/{id}/images`: сырые байты изображения, CSRF; возвращает `{images}`.
- `PATCH /api/me/tasks/{id}/images/{uuid}`: выбрать обложку; `DELETE`: удалить. Оба требуют CSRF, возвращают `{images}`. После удаления обложки выбирается первое оставшееся фото.
- `GET /api/task-images/{uuid}`: WebP с проверкой доступа к задаче.
- Task дополнен `images: [{id,url,is_cover}]`, обложка первой. Пустой массив означает отсутствие фото.

## WhatsApp

`GET/PUT /api/me/tasks/{id}/contact`: только владелец; PUT с CSRF, `{phone,enabled}`. Номер международный (8–15 цифр, без ведущего нуля; пробелы, скобки, дефисы и плюс нормализуются). При enabled=true номер обязателен. В публичный Task попадает только `whatsapp_url`, если контакт включён. Номер скрытого контакта не возвращается в каталоге. До публикации всё приватно. Ссылка открывает WhatsApp, ничего автоматически не отправляет. Формат: https://faq.whatsapp.com/5913398998672934.

## Личные сообщения

Одна беседа на пару задача + аккаунт команды. TEAM начинает её по опубликованной задаче после заполнения профиля: `POST /api/catalog/tasks/{id}/conversation`. Бизнес может открыть беседу с автором полученного отклика: `POST /api/me/proposals/{id}/conversation`. Повторное открытие возвращает тот же ID. Не является откликом или выбором команды.

- `GET /api/me/conversations`: свои беседы, название задачи, имя собеседника из профиля, последнее сообщение, счётчик непрочитанных; без email и внутренних идентификаторов пользователей.
- `GET /api/me/conversations/{id}/messages?after_id=0`: первые 100 сообщений после курсора, `has_more`, метаданные беседы. Только обе стороны.
- `POST /api/me/conversations/{id}/messages`: `{text,request_id:UUID}`, 1–4000 символов; CSRF, не более 30 новых сообщений в минуту на отправителя. Повтор одного request_id с тем же текстом возвращает прежнее сообщение; с другим текстом или беседой — 409.
- `POST /api/me/conversations/{id}/read`: `{through_id}` — прочитанный ID именно этой беседы; CSRF, курсор только возрастает.

Переписка приватна, не передаётся AI, не появляется в каталоге. Клиент показывает сообщения через textContent, опрашивает открытую беседу, сохраняет неотправленный ввод при переключении разделов в текущем окне и предупреждает при закрытии. RU/EN меняет только интерфейс. Рейтинг, публикация и выбор команды прежние.
