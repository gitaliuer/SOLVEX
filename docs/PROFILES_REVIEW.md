# Профили, языки и разбор откликов — 30.09.2026

По прямому поручению Али интегратор меняет web, сервер и новые AI-функции. Существующие задачи, профили, решения и история сохраняются миграцией.

`GET /api/me/profile` возвращает `{profile}` для обеих ролей. `PUT` + CSRF принимает name (2–100), headline (160), description (3000), industry/location (100), website (HTTP(S) либо пусто), experience (2000), team_size (80), contact (200), interests/skills/technologies (до 16 пунктов по 80). Для TEAM требуется хотя бы один навык; профиль синхронизируется с прежним `/me/team`. Email и владелец публично не раскрываются. Профили, включая явно введённый контакт, публичны: у команды в подборе и отклике, у бизнеса в опубликованной задаче. Черновики задач остаются личными.

`POST /api/me/profile/image` + CSRF принимает байты JPEG/PNG/WebP, максимум 3 MiB и 16 мегапикселей. Сервер проверяет декодирование, ориентацию, пересохраняет первое изображение в WebP до 768×768 без метаданных. Файл хранится в SQLite; URL назначается сервером. `DELETE` + CSRF удаляет фото. `/api/profile-images/{uuid}` отдаёт только сохранённое изображение, без возможности передать путь. Остальные API-запросы ограничены 32 KiB.

`GET /api/me/proposals/{id}/review?locale=ru|en` только владельцу задачи возвращает `{review:null|{strengths,questions,created_at},stale}`. `POST` + CSRF `{locale}` запускает настоящий AI-разбор одного отклика, максимум 45 секунд. Сильные стороны представлены дословной проверенной цитатой из idea/plan и полем задачи; вопросы — предположения для обсуждения, не новые факты. Нет рейтинга, победителя или автоматического решения. Сохранённый результат привязан к хешу задачи и предложения и языку. Устаревший результат помечается; сбой не подменяется заглушкой. Параллельный повтор ограничен сервером. Решения и баллы не меняются.

RU/EN сохраняется локально; язык интерфейса меняется без потери ввода. Пользовательские карточки, названия, история и профили автоматически не переводятся. Новые сообщения Agent принимают locale ru|en (по умолчанию ru); ответ модели использует выбранный язык, источники карточки остаются дословными.
