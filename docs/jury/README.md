# Материалы для защиты SOLVEX

Четыре документа Word по четыре страницы, подготовлены 30 сентября 2026 года:

1. `01_SOLVEX_Техническое_описание.docx` — архитектура и готовность к запуску.
2. `02_SOLVEX_Функции_и_применение.docx` — возможности и сценарий демонстрации.
3. `03_SOLVEX_Вопросы_жюри_и_ответы.docx` — 30 вопросов и ответов.
4. `04_SOLVEX_Развитие_и_бизнес_модель.docx` — развитие и экономика.

Документы описывают зафиксированную версию **a2144f1** до подготовки Vercel.
Изменения хостинга и облачной базы отражены в [DEPLOYMENT.md](../DEPLOYMENT.md).
Расчёты выручки являются сценариями, а не достигнутыми показателями.
